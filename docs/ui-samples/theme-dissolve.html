Theme dissolve

Switching themes today is a hard cut — every pixel snaps at once. This cross-dissolves the whole window over 240ms instead, using the View Transitions API: the old frame is snapshotted and gently fades into the new one. Try both buttons on the mock shell below; the difference is the whole pitch.

Integration: in useTheme, wrap applyColorMode() in document.startViewTransition() — only when the theme choice actually changed since the last apply (tracked in a ref: not on initial mount, not for font/density changes, not while dragging custom colours), and only when the API exists and appearance.reducedMotion is off. Plus ~8 lines of global CSS tuning ::view-transition-old/new(root) to 240ms. 'System' themes flipping with the OS get the same dissolve for free.
