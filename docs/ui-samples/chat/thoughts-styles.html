Design exploration

Five ways to show a model's thinking

Same underlying data in every option below — a real message with thinking positioned chronologically between tool calls, exactly what shipped this week. What differs is only the visual treatment: how much weight it carries, how it reads while streaming, and how it sits next to the tool timeline. All built from existing Anodex tokens, nothing new.

A

Minimal Rail

closest to what shipped

The current pattern, refined: a thin connecting rail (the same visual language as the tool timeline) runs through the expanded body, so a thought reads as part of one continuous line down the message rather than a boxed-off aside. Lowest-risk option — an evolution, not a rebuild.

B

Quiet Marginalia

lowest visual weight

No card, no chrome — just a rule and a single truncated preview line, like a note in the margin. It never competes with the real answer for attention; you only ever see the full text if you deliberately go looking for it.

C

Gradient Pulse

brand accent, streaming only

Spends Anodex's reserved cyan→violet mark gradient on exactly one moment: while the model is actively reasoning right now. The orb spins through the brand ramp only in that instant, then settles to a flat, quiet grey the moment it's done — the same restraint the model-download progress bar already uses for that gradient.

D

Compact Chip

smallest footprint

Thinking becomes a small pill — "Thought for 4s" — the same chip language the app already uses for model badges and counts. It never takes up a full line in the timeline; expanding opens a floating popover instead of pushing everything else down. Best for someone who wants thinking out of the way almost all the time.

E

Timeline Node

most literal answer to "put it in the timeline"

Thinking and tool calls share one continuous rail down the message — a dashed node for a thought, a filled checkmark node for a completed action. Reads as a single connected process rather than separate block types that happen to be near each other. The most structural option, and the most work to build.
