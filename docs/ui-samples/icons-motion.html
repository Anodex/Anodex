01 · Audit

What the review found

The current set is a clean Lucide-style stroke system — good bones, worth keeping. The problems are duplicates, a few glyphs that misread, and motion that feels mechanical.

settings ≡ slidersThe two glyphs are pixel-identical. Settings has no identity of its own.
web ≈ globeSame circle-and-meridian drawing; globe just adds two arcs. One of them should mean something else.
palette misreadsCircle + arc + ticks reads as a gauge or compass, not appearance.
Noise at 18pxsparkle's extra plus + circle and puzzle's 1,000-character path turn to mud at render size.
No brand threadAnodex is a hexagon mark, but no glyph or motion carries that geometry.
Spinner is mechanicalConstant 90° arc, 0.7s linear. It rotates; it doesn't feel like work is happening.
Thinking phrases hard-swapText changes every 2s with no transition, which reads as flicker in the periphery.
Caret hard-blinkssteps(1) 50% blink is a terminal idiom; a soft breathe reads calmer during streaming.

02 · System signature

The facet — a 45° cut corner

Two existing glyphs (file, save) already carry a clipped top-right corner. The proposal promotes that accident into the system's signature: every container-shaped glyph gets exactly one 45° facet, echoing the hexagon logo's angles. One rule, applied consistently — enough to make the set ownable without turning it into a gimmick.

09 · Recommendation

What I'd ship

  1. Icons: facet system (chat, folder, folder-plus, copy, image) + the seven redesigns — hex-nut settings, hex-cell models, hex bot, contrast appearance, node web, refined sparkle, plug integrations. Add the five new glyphs.
  2. Spinner: Comet replaces the current ring everywhere (same component API). Hex Trace is reserved for brand moments — model loading, app boot.
  3. Thinking: breathing sparkle + shimmer + phrase crossfade as one composed indicator.
  4. Micro: breathing caret, status-dot halo, comet bar on running tool cards.
  5. Everything honors data-reduced-motion / prefers-reduced-motion exactly like the app already does.
