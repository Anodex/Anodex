Drift stretches to cover however long init actually takes — stars keep moving, the status line keeps talking, so a 4-second cold start still feels alive. Ignition is the anticipation beat: stars nearly stop, the mark brightens, then the field explodes forward.

Wiring it to real readiness

  1. Overlay mounts beside the shell. In App.tsx the overlay renders as a sibling of AppShell — the real UI paints underneath from frame one; nothing waits on the animation.
  2. Milestones are the real hydrate sequence. The steps in useAnodexBridge.ts → hydrate() (settings → workspace → model refresh → services) report to a small startup store; "ready" is hydrate() resolving, never a timer.
  3. Model loading never blocks entry. restoreLastModel() already runs deferred and non-blocking; the overlay only checks models, and the shell's status chip carries any load still in flight.
  4. Failure settles, it doesn't crash the theatre. A throwing hydrate step eases the stars to a stop, dims the mark, and offers Retry / Open Settings. Recovery paths skip the jump — the celebration is only for a clean start.
  5. First launch detection. settings.model.autoConfigured === false selects the longer drift floor and extended 950 ms jump.
  6. Reduced motion. prefers-reduced-motion swaps the tunnel for a static field, a 1.05× scale-fade of the mark, and no flash. Status updates are unaffected.
  7. One paint color. Align BACKGROUND_COLOR in window.ts (currently #0A0E1A) with --bg-base #080808 so window paint, overlay, and shell are seamless.
