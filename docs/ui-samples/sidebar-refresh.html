What changed, numbered

  1. New chat becomes the primary action — a real button at the top instead of a small + buried in a section header. Project-aware, with its shortcut on it.
  2. Search relaxes — borderless ghost row at rest, full input on focus. Less chrome before you need it.
  3. Tools rail sharpens — fixed icon gutter, accent-tinted icon + soft fill for the active view, optional count badges (scheduled runs due, unread mail).
  4. Section headers calm down — the count sits with the title; header actions only appear when your pointer is in the section.
  5. The workspace becomes a real tree — chevron + folder in a fixed gutter, chats indented under a 1px guide line, every row the same 30px height.
  6. Live and unread keep the signals the app already has — the comet scan under a running chat's title stays exactly as shipped, gaining only an accent-tinted live timer beside it; unread keeps its existing accent dot. (The earlier breathing-dot idea is dropped — the comet was already better.)
  7. The footer stops truncating your model into mystery — middle truncation keeps the version/variant visible ("Qwen3.5-27B-Claude…-4.6-Instruct"), the status dot gets a soft glow, and model + profile become two tidy hover rows.
